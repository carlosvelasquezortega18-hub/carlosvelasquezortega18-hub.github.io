📚 Contenido

SEMANA 3

SQL avanzado

En esta semana desarrollamos consultas SQL para obtener información específica de una base de datos.

📚 Contenido

  • SELECT
  • WHERE
  • ORDER BY
  • GROUP BY
  • HAVING

💻 Ejemplo SQL


SELECT nombre, edad
FROM estudiantes
WHERE edad >= 18
ORDER BY nombre;

🎯 Lo aprendido

Aprendí a realizar consultas para buscar, ordenar y filtrar información.
