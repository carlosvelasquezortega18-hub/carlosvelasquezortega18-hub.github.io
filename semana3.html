Semana 3: SQL Avanzado

Información

SQL permite realizar diferentes operaciones sobre una base de datos, como consultar, insertar, modificar y eliminar información.

Contenido

  • Lenguaje SQL.
  • SELECT.
  • WHERE.
  • ORDER BY.
  • GROUP BY.
  • HAVING.
  • Funciones SQL.

Tarea

Crear consultas SQL para seleccionar, ordenar y agrupar información de una base de datos.

Lo aprendido

Aprendí a utilizar consultas SQL para obtener información específica de las tablas de una base de datos.
